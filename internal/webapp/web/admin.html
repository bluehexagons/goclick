Formats and account access

Go Click backups restore saved passwords and roles. Rails SQLite preserves original IDs, passwords, roles, and all entity records; its source must contain an administrator. Rails JSON omits passwords and requires explicit administrator password setup below.

Administrator access after JSON migration

JSON omits passwords. Choose an account from the export and set its new password; it will have administrator access. Other imported accounts need operator-set passwords. Export with “Fetch User Entities” enabled.

Rails merge import

Merge Rails players into current data

Import the primary SQLite database to keep existing passwords, or the admin JSON download with “Fetch User Entities” enabled to carry progress. New JSON accounts need an operator-set password before they can sign in.

Imports keep original IDs and refuse conflicts. For an initial migration with conflicting IDs, use Restore or migrate a database above. A pre-import snapshot is saved. SQLite: 128 MiB maximum; JSON: 16 MiB.
