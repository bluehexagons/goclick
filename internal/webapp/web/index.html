Game & storage notes

Clicks & saves

Releasing inside the button adds one click. Holding does not add extra clicks. The total shows server-confirmed saves; pending clicks appear separately. Failed requests are not retried automatically.

Streak periods

Days, calendar months, and calendar years use UTC. Multiple clicks in the same period do not extend a streak. The next click after a missed period starts that streak at one.

Ping & storage

Ping measures the last successful click request, including server processing. Amber means a request is in flight; red means a save failed. Progress is stored in SQLite on the server, so signing out does not delete it.

Account sessions

Signing in uses an HttpOnly session cookie. Passwords are stored as bcrypt hashes. Signing out revokes the current session; account data stays available when you sign in again.
